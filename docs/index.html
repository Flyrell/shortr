shortr

Long links in, short links out. Every link expires. Nothing to sign up for.

A URL shortener and QR code generator. A Go 1.27 API built on Fiber v3 serves the JSON endpoints, the redirects and a plain TypeScript client from the same binary — one Docker image, no accounts, no tracking.

Quick start

docker run

Build the production image and run it. With no URL_PERSISTER set, links are kept in memory and nothing else is needed. 

docker build -f .docker/Dockerfile -t shortr:latest .
docker run --rm -p 8080:8080 shortr:latest

Serving from another origin? Add -e BASE_URL=https://s.example.com so the returned links point at it.

docker compose

The development stack runs the API with hot reload, the client watcher and Redis, driven by Task. 

cp .env.example .env
task project:start
task project:stop

Both land on http://localhost:8080. project:stop drops the stack's volumes.

Configuration

Everything is read from the environment at startup; an invalid value aborts the start with an error naming the variable.

API

POST /api/shorten

Requires Content-Type: application/json. Rate limited and bot filtered. Answers 201 with the code, the short URL and an RFC 3339 expiresAt. 

curl -X POST http://localhost:8080/api/shorten \
  -H 'Content-Type: application/json' \
  -d '{"url":"https://example.com/a-rather-long-link"}'
{
  "code": "aB3xY7kQ1mZp",
  "shortUrl": "http://localhost:8080/aB3xY7kQ1mZp",
  "expiresAt": "2026-10-05T12:00:00Z"
}

Errors share one shape, {"error": "invalid_url", "message": "…"}: 400 invalid_body, 400 invalid_url, 403 forbidden, 413 body_too_large, 415 unsupported_media_type, 429 rate_limited, 500 internal.

GET /{code}

302 Found to the target with Cache-Control: no-store. Neither rate limited nor bot filtered. 404 not_found when the code is unknown, expired, or not 12 characters of [0-9A-Za-z].

GET /healthz

200 {"status":"ok"} when the adapter answers a ping, 503 unavailable when it does not. Not bot filtered, so probes with any user agent work.

GET /, /robots.txt, /favicon.svg, /assets/*

The built client, served from STATIC_DIR; assets carry a one hour max-age. All bot filtered.

Client

Plain HTML, CSS and TypeScript bundled by esbuild and served by the API. No external requests at runtime.

  • Two modes — Shorten URL and QR code as a tablist. The choice is stored in localStorage under shortr.mode; the default is Shorten URL.
  • Keyboard — roving tabindex on the tabs: Left and Right move, Home and End jump to the ends. The URL input is focused on load and Enter submits.
  • Clipboard — the result is copied automatically, the short URL as text or the QR code as a PNG through ClipboardItem, with a toast in an aria-live region. Clicking the result copies again; when the clipboard is unavailable the toast says so instead.
  • Expiry — directly under the short code the result card shows when the link dies, built from the expiresAt of the response: the largest whole unit left and the date, for example Expires in 30 days · 4 Oct 2026.
  • Errors render inline with role="alert"; a 429 adds the seconds to wait, read from Retry-After.

Development

Everything runs in Docker — no Go or Node toolchain on the host, only Docker and Task. The API container rebuilds on every Go change with air; the client container runs the esbuild watcher and the API serves its output.

Tasks
TaskWhat it does
task project:startBuild and start the development stack.
task project:stopStop it and drop its volumes.
task project:lintLint the API, the client and the e2e suite.
task project:testRun the API and client unit tests.
task project:e2ePlaywright suite against the production image.
task api:buildBuild the production image shortr:latest.
task client:buildBundle the client into apps/client/dist.

The production image is distroless and runs as nonroot: the static binary plus the built client in /srv/client, nothing else. With no shell inside, health probes go through GET /healthz.

Writing an adapter

Storage lives behind one interface. Adding a backend touches adapters/<name>.go, its test and a single case in adapters.New — nothing else in the codebase learns about it. 

type Env func(key string) (string, bool)

type Adapter interface {
    SaveURL(ctx context.Context, code, target string, ttl time.Duration) error
    FindURL(ctx context.Context, code string) (string, error)
    Ping(ctx context.Context) error
    Close() error
}

Implement the four methods — ErrCodeTaken when the code exists, ErrNotFound when it is missing or expired — read and validate your own environment variables from the Env lookup the constructor receives, register one case in adapters.New, and add tests. Rate limiting, code generation and URL validation are not adapter concerns.

Security

  • Rate limiting through Fiber's limiter, a fixed window keyed by client IP, attached to the /api group only. Counters live in the process, so each replica enforces its own limit; behind a proxy set TRUSTED_PROXIES.
  • Not indexable — X-Robots-Tag: noindex, nofollow, noarchive on every response, <meta name="robots" content="noindex, nofollow"> on the page, a robots.txt that disallows everything, and 403 for known crawler and scraper user agents on the client files and the API. Redirects and /healthz stay open.
  • Headers — a strict Content-Security-Policy (default-src 'self', no inline scripts or styles, frame-ancestors 'none'), nosniff, X-Frame-Options: DENY and Referrer-Policy: no-referrer.
  • Codes are 12 characters of [0-9A-Za-z] drawn from crypto/rand without modulo bias — around 71 bits, so links cannot be enumerated.
  • Everything expires after URL_TTL, 30 days by default. Bodies are capped at 4096 bytes and target URLs at 2048 characters.
